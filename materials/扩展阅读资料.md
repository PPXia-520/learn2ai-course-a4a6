# 扩展阅读资料：互联网开源学习资源合集

> 用途：这份文档只做一件事——把你从「不知道该读什么」里解放出来。
> 每一条都是可自由访问的开源项目或官方文档，并标注了「在课程的哪一章读它」和推荐理由。

## 一、怎么用这份清单

1. **按章取用**：读某章讲义时，先看该章 README 指向的条目，不要一次全部打开。
2. **一主一辅**：每个主题挑「1 个系统教程 + 1 个速查/清单」，贪多是最常见的失败原因。
3. **带问题去读**：先写下你的疑问，再去搜条目里的关键词，读完回来更新自己的笔记。
4. **看星标但别只看星标**：★ 只代表流行度；重点看条目末尾的「用在」与推荐理由是否匹配你当前阶段。

**图例** — `★` GitHub 星标数（2026-10-07 通过 GitHub API 实测快照）；`用在` 指本课程对应章节。
