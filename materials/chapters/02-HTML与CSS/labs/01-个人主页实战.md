# Lab 02 · 响应式个人主页实战

## 目标
用纯 HTML + CSS（不引入任何框架）做一个响应式个人主页，把本章全部知识点用上一遍。

## 前置
- 读完《01-HTML语义化与可访问性.md》与《02-CSS布局与响应式设计.md》。
- 本地已有编辑器与浏览器，无需构建工具（本章刻意用原生方式，第 04 章再上工具链）。

## 需求
1. **页头**：姓名 + 一句话简介 + 导航（关于我、技能、项目、联系方式）。
2. **关于我**：一张头像 + 两段自我介绍。
3. **技能**：卡片墙，每张卡片含技能名与熟练度，≥6 项。
4. **项目**：≥3 个项目卡片，含标题、一句话描述、技术标签、仓库链接。
5. **联系方式**：一个带校验提示的表单（邮箱 + 留言）。
6. **页脚**：版权信息与社交链接。

## 分步实现
1. **写骨架**：只写 HTML，全部使用语义标签，先不写任何 CSS。检查标题层级与 `alt`。
2. **移动优先基础样式**：设置 `box-sizing`、字体、颜色变量（CSS 自定义属性）、容器间距，长度单位用 `rem`。
3. **单列布局**：默认所有区块单列纵向排列，卡片墙用 Grid 的 `auto-fit` 写法。
4. **加断点**：768px 时导航横向排列、项目卡片两列；1200px 时内容居中限宽 1100px。
5. **加交互反馈**：链接与按钮的 `:hover`、`:focus-visible`；卡片悬浮用 `transform` 位移。
6. **深色模式**：用 `prefers-color-scheme` 提供深色配色，确保对比度仍达标。
7. **自查**：分别用 375px、768px、1440px 宽度截图，跑一次 Lighthouse。

## 验收清单
- [ ] 三种宽度下均无横向滚动条，无文字重叠或溢出。
- [ ] 页面只用一个 `h1`，标题层级连续，全部区块用语义标签。
- [ ] 所有图片有 `alt`，装饰性图片用空 `alt`。
- [ ] 键盘 Tab 可到达所有链接与按钮，且焦点样式清晰可见。
- [ ] 只用 CSS 变量控制主色，改一处即可换主题。
- [ ] 深色模式下文字对比度达标，无「黑底黑字」。
- [ ] `!important` 出现 0 次。
- [ ] 三张截图与 Lighthouse 无障碍分数一起提交。

## 常见卡点
| 卡点 | 提示 |
| --- | --- |
| 卡片墙在窄屏挤成一列但间距不均 | 检查 `gap` 是否写在 Grid 容器上 |
| 导航在手机端挤成两行 | 手机上导航改为纵向列表，或加 `flex-wrap` |
| 深色模式下背景仍然发白 | 检查 `body` 背景是否也用了变量 |
| 截图宽度与预期不符 | 用开发者工具的设备模拟，或直接拖拽窗口后刷新 |
