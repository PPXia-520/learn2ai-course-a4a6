## 二、Node 版本管理

不同项目需要不同 Node 版本，用版本管理器切换比手装多个安装包可靠得多。

```powershell
# 方案 A：nvm-windows
winget install CoreyButler.NVMforWindows
nvm install lts
nvm use lts
node -v

# 方案 B：volta（自动按项目切换）
winget install Volta.Volta
volta install node@20
```

**建议**：项目根目录写 `.nvmrc`（内容如 `20`），团队就知道该用哪个版本。

## 四、终端与编码

```powershell
# 让 PowerShell 的输入输出都用 UTF-8，避免中文乱码
$OutputEncoding = New-Object System.Text.UTF8Encoding($false)
[Console]::OutputEncoding = New-Object System.Text.UTF8Encoding($false)
chcp 65001
```

把上面三行写进 PowerShell 配置文件（`$PROFILE` 指向的文件）即可长期生效。建议再设置：

- 终端字体：等宽字体（如 Cascadia Code、JetBrains Mono），开启连字更易读；
- 常用别名：`g` → `git`、`gs` → `git status`、`ll` → `Get-ChildItem`；
- 提示符显示当前 Git 分支（可用 oh-my-posh），能显著减少「改错分支」的事故。

## 五、用 Docker 起本地数据库与缓存

新建 `infra/docker-compose.yml`：

```yaml
services:
  db:
    image: postgres:16
    container_name: local-db
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: app_dev_only
      POSTGRES_DB: app_dev
    ports:
      - 5432:5432
    volumes:
      - db-data:/var/lib/postgresql/data
    healthcheck:
      test: [CMD-SHELL, pg_isready -U app]
      interval: 5s
      retries: 10
  cache:
    image: redis:7
    container_name: local-cache
    ports:
      - 6379:6379
volumes:
  db-data:
```

```powershell
cd infra
docker compose up -d
docker compose ps
docker exec -it local-db psql -U app -d app_dev -c 'select version();'
```

## 八、一键自检脚本

```powershell
$checks = @(
  @{ name = 'node';   cmd = 'node -v' },
  @{ name = 'pnpm';   cmd = 'pnpm -v' },
  @{ name = 'git';    cmd = 'git --version' },
  @{ name = 'docker'; cmd = 'docker version --format {{.Server.Version}}' }
)
foreach ($c in $checks) {
  try {
    $result = Invoke-Expression $c.cmd 2>&1
    Write-Output ('[OK]   ' + $c.name + ' -> ' + $result)
  } catch {
    Write-Output ('[FAIL] ' + $c.name + ' -> ' + $_.Exception.Message)
  }
}
```

把输出保存为 `work/.../labs/env-report.md`，作为本章产出。

## 九、常见安装问题

| 现象 | 处理 |
| --- | --- |
| `docker` 命令找不到 | 安装后重启终端；Windows 需开启 WSL2 或 Hyper-V |
| Docker 启动报端口占用 | 改 `docker-compose.yml` 的宿主端口（如 `5433:5432`） |
| `pnpm` 不是内部或外部命令 | 执行 `corepack enable` 后重开终端 |
| `psql` 未找到 | 无需本地安装，用 `docker exec -it local-db psql ...` |
| 数据库连不上 | 确认容器在 Up、端口映射正确、用户名密码与连接串一致 |
| 编辑器格式化不生效 | 检查默认格式化器与 `formatOnSave` 是否开启，是否装了 Prettier |
