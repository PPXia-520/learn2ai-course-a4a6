# Lab 05 · 单页应用实战

## 目标
用 React + TypeScript 做一个有真实形态的单页应用。主题自选但需满足下面的功能矩阵，建议做一个「团队任务看板」或「个人记账本」。

## 功能矩阵（必须全部实现）
| 模块 | 要求 |
| --- | --- |
| 路由 | ≥4 个页面：列表、详情（动态参数）、新建/编辑、设置或统计；含 404 页 |
| 列表 | 支持关键字搜索、状态筛选、排序；筛选条件写入 URL 查询串 |
| 详情 | 按 `id` 拉取数据，处理「不存在」的情况（展示友好提示） |
| 表单 | 受控组件 + 必填/格式校验 + 提交中禁用 + 错误提示 |
| 数据层 | 统一的请求封装（错误处理 + 取消）；加载态、错误态、空态齐全 |
| 状态 | 至少一处跨组件共享状态（用户偏好或筛选），说明为何这样放 |
| 持久化 | 用户偏好写入 localStorage，刷新后保持 |
| 测试 | 覆盖列表成功、列表失败、表单校验失败三条路径 |

## 技术要求
- TypeScript 严格模式，零 `any`。
- 至少 2 个自定义 Hook，并在两处以上复用。
- 列表 `key` 使用业务 id；不使用数组下标。
- 所有请求在组件卸载时取消。
- 至少一处 `React.lazy` + `Suspense` 的路由级懒加载。

## 建议结构
```text
board-app/
  src/
    app/
      router.tsx
      query-client.ts
    features/
      tasks/
        api.ts
        hooks.ts
        components/
        types.ts
    shared/
      components/    # Button、EmptyState、ErrorBox、Spinner
      hooks/         # useDebouncedValue、useLocalStorage
    styles/
  tests/
```

## 分步实现
1. **定类型**：先写 `types.ts`，把领域模型与接口出入参定义清楚。
2. **搭骨架**：路由 + 布局 + 404，先渲染假数据。
3. **接数据**：封装 `api.ts`（统一错误处理），接入请求库，处理三态。
4. **做交互**：搜索防抖、筛选写进 URL、表单校验、提交后刷新列表。
5. **抽公共件**：把重复出现的加载／空／错误界面抽成组件。
6. **加懒加载**：把最重的页面改成 `lazy` + `Suspense`。
7. **写测试**：三条路径各一个用例。
8. **性能自查**：Profiler 找出一次多余重渲染并修复，写下优化前后数据。
