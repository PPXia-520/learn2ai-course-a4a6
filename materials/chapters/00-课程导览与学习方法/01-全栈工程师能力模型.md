# 01 · 全栈工程师能力模型

## 一、为什么要先谈能力模型

初学者最常见的两个误区：

1. **「全栈 = 什么都学一点」** —— 结果是每个方向都停在教程水平，无法独立交付。
2. **「先把所有理论学完再动手」** —— 结果是学了半年还在第一章。

正确的理解是：全栈工程师的本质是**能在一条完整链路上独立负责**——从需求、界面、接口、数据到部署，任何一环出问题都能定位并修复。

## 二、四象限能力模型

见 `assets/capability-map.svg`。四个象限对应四类能力，缺一整块就会在真实工作中被卡住：

| 象限 | 包含能力 | 缺失时的典型症状 | 对应章节 |
| --- | --- | --- | --- |
| 语言与框架 | HTML/CSS、JavaScript/TypeScript、React、Node | 写不出功能，看不懂别人的代码 | 02–06 |
| 工程与交付 | Git、构建工具、测试、Docker、CI/CD | 代码只在本地能跑，不敢改、不敢发 | 01、04、09、10 |
| 数据与架构 | SQL、数据建模、缓存、系统设计、设计模式 | 需求一变就推倒重来，性能问题无从下手 | 07、11 |
| 协作与表达 | 安全与规范、代码评审、文档、方案表达 | 方案说不清、评审被反复打回、面试讲不出亮点 | 08、12、13 |

## 三、T 型结构：深度与广度

```
        广度（能协作、能读懂、能改动）
   ┌───────────────────────────────────────┐
   │  HTML/CSS · TS · Node · SQL · Docker · 架构 │
   └───────────────────┬───────────────────┘
                       │
                  深度（能独立交付）
                       │
              前端 或 后端 或 全链路
```

- **竖线（深度）**：选一个主方向做到「能独立设计并交付一个生产级模块」。本课程默认以**全链路 Web 应用**为深度目标。
- **横线（广度）**：其余方向达到「能读懂、能改动、能协作评审」的程度。
- **取舍原则**：时间有限时，先加深深度的 1 厘米，再拓展广度的 1 米。没有深度的广度只是简历上的词。

## 四、三个成长阶段

| 阶段 | 特征 | 判定标准 | 大致对应 |
| --- | --- | --- | --- |
| 入门 | 跟着教程能做出东西 | 能独立复现教程项目并解释每行代码 | 第 02–05 章 |
| 独立 | 没有教程也能做出东西 | 能读懂报错、查文档、拆解需求并交付 | 第 06–10 章 |
| 设计 | 能决定「该怎么做」 | 能做技术选型、写设计文档、评估利弊与风险 | 第 11–13 章 |

## 五、能力自评表（现在做第一次）

每题按 0–5 分自评（0 = 完全没接触，5 = 能独立交付并指导他人），写在笔记里并标注日期：

**A. 语言与框架**
1. 我能不查资料写出语义化的 HTML 结构与响应式布局。
2. 我能解释闭包、原型链、`this` 与事件循环。
3. 我能用 TypeScript 定义接口、泛型与联合类型。
4. 我能用 React（或其它框架）实现一个多页面交互应用。
5. 我能用 Node.js 写一个可用的 HTTP 服务。

**B. 工程与交付**
6. 我能用 Git 分支协作并处理冲突。
7. 我能解释构建工具做了什么，并能配置环境变量与代理。
8. 我能为代码写出单元测试与接口测试。
9. 我能把应用容器化并写一条 CI 流水线。

**C. 数据与架构**
10. 我能设计满足第三范式的表结构并说明索引取舍。
11. 我能识别并修复 N+1 查询等性能问题。
12. 我能为一个业务场景画出架构图并说明关键取舍。

**D. 协作与表达**
13. 我能清晰描述一个问题的最小可复现步骤。
14. 我能读懂并给出有价值的代码评审意见。
15. 我能在 5 分钟内讲清楚我做过的项目的技术难点与方案。

**怎么用结果**：总分 < 20 → 踏踏实实从第 01 章开始；20–40 → 如实按章推进，但可加快阅读节奏；> 40 → 可把重点放在第 07、11、12 章与项目实战。无论分数多少，**第 12 章结束时再自评一次**，对比两次差距就是你真实的成长。

## 六、本课程不承诺的三件事

1. 不承诺「背完就能就业」：本课程给你路线与练习，就业取决于你能拿出多少真实产出。
2. 不承诺覆盖所有技术栈：选型以当前主流、生态健康、学习曲线合理为准。
3. 不承诺一次学会：任何一项能力都需要「学 → 做 → 卡住 → 查 → 再做」的反复循环。

## 小结

- 全栈 = 一条完整链路 + 一个方向的深度。
- 四象限缺一不可：语言与框架、工程与交付、数据与架构、协作与表达。
- 用自评表定位现在的自己，24 周后再测一次。
