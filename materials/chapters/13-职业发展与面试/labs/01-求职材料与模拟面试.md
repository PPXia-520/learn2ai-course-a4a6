# Lab 13 · 求职材料与模拟面试

## 目标
把课程产出转化为求职材料，并通过一次模拟面试暴露表达上的问题。

## 任务一 · 简历
1. 一页简历，结构：抬头 → 技能摘要 → 项目经历（2–3 个）→ 经历／教育。
2. 每个项目 3–5 条 STAR 条目，每条必须包含至少一个量化结果。
3. 技能栏写成「能力 + 证据」，删除所有没有证据的形容词。
4. 全篇不出现「精通」；所有链接逐个点开验证可用。

## 任务二 · 作品集入口
1. 在 GitHub 主页 README（或个人站点）列出项目，每个含：
   - 一句话定位；
   - 线上地址；
   - 技术栈；
   - 3 个亮点（含一处难点与解法）；
   - README 与设计文档链接。
2. 请一位同学按你的 README 跑一次项目，记录他卡住的步骤并修复。

## 任务三 · 面试题库
产出 `interview-prep.md`，包含四部分：

| 部分 | 数量要求 | 说明 |
| --- | --- | --- |
| 项目追问 | ≥10 题 | 每题 3 句话答案提纲 |
| 基础原理 | ≥20 题 | 按第 03／06／07／08 章覆盖四类主题 |
| 场景设计 | ≥3 题 | 每题写五步框架答案 |
| 行为故事 | 5 个 | 每个含 30 秒与 90 秒两版 |

## 任务四 · 模拟面试
1. 找一位同学（或使用录制工具）进行 30 分钟模拟面试：15 分钟项目深挖 + 10 分钟基础 + 5 分钟反问。
2. 全程录音或录像。
3. 复盘并产出 `mock-interview.md`：
   - 被问到但答不上来的问题（≥3 条）与改进后的答案；
   - 表达问题（如超时、绕圈、缺少结论）；
   - 三个具体改进动作与期限。

## 任务五 · 能力再盘点
回到第 00 章的四象限自评表，重新打一次分，与第一次对比：

| 数据与架构 | | | |

## 验收清单
- [ ] 简历一页，无「精通」，所有链接可用。
- [ ] 每个项目条目都有量化结果，且与真实情况一致（能被追问 3 层）。
- [ ] 作品集入口含线上地址，且陌生人能按 README 跑起来（附他卡住的地方）。
- [ ] `interview-prep.md` 四部分数量达标。
- [ ] `mock-interview.md` 含 ≥3 条改进前后的答案对比与 3 个改进动作。
- [ ] 能力四象限有前后两次评分与变化原因。
- [ ] 3 分钟项目口述稿已录音，且能控制在 3 分钟内。

## 加分项
1. 写一篇技术笔记并在公开平台发布（含项目中的一个真实坑与解法）。
2. 给一个开源项目提一个 PR（文档修正也算），并记录评审往返过程。
3. 用英文准备一份项目介绍，练习跨境岗位面试。

## 提交要求
把 `resume.md`（或 PDF）、作品集链接、`interview-prep.md`、`mock-interview.md` 与能力对比表放进
`work/<你的用户UUID>/<作业UUID>/labs/lab13/`。
这是课程的最后一站：请把材料交给一位真实的人看一次，而不是只给自己看。
