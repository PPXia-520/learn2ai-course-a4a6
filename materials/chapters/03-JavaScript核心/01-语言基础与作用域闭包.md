# 01 · 语言基础与作用域闭包

## 一、类型系统

JavaScript 有 7 种原始类型与 1 种引用类型：

| 分类 | 类型 | 说明 |
| --- | --- | --- |
| 原始值 | `string` `number` `boolean` `null` `undefined` `symbol` `bigint` | 按值传递，不可变 |
| 引用值 | `object`（含数组、函数、日期等） | 按引用传递，比较的是地址 |

```js
typeof 1;            // 'number'
typeof 'x';          // 'string'
typeof undefined;    // 'undefined'
typeof null;         // 'object'  ← 历史遗留缺陷，判断 null 用 x === null
typeof [];           // 'object'  ← 用 Array.isArray() 判断数组
typeof (() => {});   // 'function'
```

**类型转换的两个高频陷阱**：

```js
1 == '1';        // true —— 触发了隐式转换
1 === '1';       // false —— 推荐写法
[] + {};         // '[object Object]'
'' == false;     // true —— 空字符串会被转成 0/false
Number.isNaN(NaN);          // true，比 isNaN 安全（不做隐式转换）
Object.is(NaN, NaN);        // true
```

## 二、作用域与闭包

```js
// var：函数作用域，存在变量提升
function legacy() {
  if (true) { var x = 1; }
  console.log(x);          // 1 —— x 泄漏到函数作用域
}

// let / const：块级作用域，存在暂时性死区
function modern() {
  if (true) { let y = 1; }
  // console.log(y);      // ReferenceError
}
```

**闭包**：函数与其定义时所在词法作用域的组合。内部函数能持续访问外层变量，即使外层函数已经返回。

```js
function createCounter(start = 0) {
  let count = start;                 // 被闭包捕获，外部无法直接访问
  return {
    inc: () => ++count,
    dec: () => --count,
    get value() { return count; },
  };
}

const c = createCounter(10);
c.inc(); c.inc();
console.log(c.value);   // 12
```

闭包的三个真实用途：

| 用途 | 说明 |
| --- | --- |
| 数据私有 | 上面的 `count` 只能通过方法访问，无法被外部改坏 |
| 记忆化 | 缓存计算结果，避免重复耗时 |
| 防抖／节流 | 用闭包保存计时器 id 与上次执行时间 |

```js
export function debounce(fn, wait = 300) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), wait);
  };
}
```

**注意**：闭包会延长变量生命周期。若在循环中大量创建闭包并引用大对象，会造成内存占用升高——通常问题在于你把整个大对象都关进了闭包，只捕获需要的那几个字段即可。

## 三、`this` 的四种绑定（按优先级）

| 绑定方式 | 例子 | `this` 指向 |
| --- | --- | --- |
| new 绑定 | `new Foo()` | 新创建的对象 |
| 显式绑定 | `fn.call(obj)` / `fn.apply(obj)` / `fn.bind(obj)` | 传入的对象 |
| 隐式绑定 | `obj.method()` | `obj` |
| 默认绑定 | `fn()` | 严格模式下 `undefined` |
| 箭头函数 | `() => {}` | **继承外层**，不受上面规则影响 |

```js
const timer = {
  seconds: 0,
  start() {
    setInterval(() => {
      this.seconds++;            // 箭头函数继承了 start 的 this
    }, 1000);
  },
};
```

## 四、原型与 class

```js
function Animal(name) { this.name = name; }
Animal.prototype.speak = function () { return `${this.name} 发出声音`; };

class Dog extends Animal {
  speak() { return `${this.name} 汪汪`; }
  static create(name) { return new Dog(name); }
}
```

- 属性查找顺序：对象自身 → 原型 → 原型的原型 → …… → `null`。
- `class` 是原型继承的语法糖，但必须用 `new` 调用，且方法默认不可枚举。
- 判断关系：`dog instanceof Animal` 为 `true`；`Object.getPrototypeOf(dog)` 拿到原型对象。

## 五、数组与对象的高频操作

| 目的 | 写法 |
| --- | --- |
| 变换 | `items.map(i => i.price * 2)` |
| 过滤 | `items.filter(i => i.stock > 0)` |
| 聚合 | `items.reduce((sum, i) => sum + i.price, 0)` |
| 查找 | `items.find(i => i.id === id)` |
| 排序 | `[...items].sort((a, b) => a.price - b.price)`（不要原地改原数组） |
| 判断 | `items.some(...)` / `items.every(...)` |
| 分组 | `Object.groupBy(items, i => i.category)`（新特性，可自行 polyfill） |

```js
// 解构、展开、可选链、空值合并
const { name, tags = [] } = user;
const next = { ...user, name: '新名字' };
const city = user?.address?.city ?? '未知';
```

**不可变更新**是 React 等框架的基础，务必练熟：

```js
const addItem = (list, item) => [...list, item];
const removeItem = (list, id) => list.filter(i => i.id !== id);
const updateItem = (list, id, patch) =>
  list.map(i => (i.id === id ? { ...i, ...patch } : i));
```

## 六、常见坑

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 循环里的 `var` 全部输出最后一个值 | `var` 无块级作用域 | 改用 `let` |
| `[1, 2, 10].sort()` 得到 `[1, 10, 2]` | 默认按字符串排序 | 传比较函数 |
| `sort` 改动了原数组 | 数组方法是原地操作 | 先展开复制再排序 |
| `0.1 + 0.2 !== 0.3` | 浮点数二进制表示 | 用整数分账或 `Number((a+b).toFixed(2))` |
| 对象浅拷贝后改嵌套属性影响了原对象 | 展开运算只做浅拷贝 | 用 `structuredClone()` 做深拷贝 |
| 异步循环里全部拿到同一个值 | 闭包捕获了同一个变量 | 用 `let` 或在循环内创建新作用域 |
