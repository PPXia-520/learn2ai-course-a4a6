# Lab 03 · 原生 JavaScript 待办应用

## 目标
不借助任何框架，用原生 DOM API 完成一个可用的待办应用，把本章三个文档的知识全部用上。

## 需求
1. 新增任务（输入框 + 按钮 + 回车键都能触发）。
2. 勾选完成 / 取消完成，完成项样式有区分。
3. 删除任务。
4. 编辑任务标题（双击进入编辑，回车保存，Esc 取消）。
5. 筛选：全部 / 未完成 / 已完成。
6. 统计：剩余未完成数量。
7. 刷新页面后数据不丢失（localStorage）。
8. 空状态提示（无任务时显示引导文案）。

## 技术要求
- 事件全部使用**事件委托**绑定在列表容器上。
- 渲染使用 `DocumentFragment` 批量插入，不允许用 `innerHTML` 拼字符串。
- 状态更新遵循**不可变更新**：`add` 用展开、`remove` 用 `filter`、`update` 用 `map`。
- 数据读写封装在 `storage.js`，解析失败时返回空数组而不是抛错。
- 输入内容使用 `textContent` 写入，禁止把用户输入拼进 HTML。

## 建议结构
```text
todo-app/
  index.html
  styles.css
  src/
    store.js       # 状态与不可变更新函数
    storage.js     # localStorage 读写与容错
    render.js      # 渲染函数（根据状态重绘列表）
    events.js      # 事件委托与键盘交互
    index.js       # 组装入口
```

## 分步实现
1. 先写 `store.js`：定义状态结构 `{ todos: [], filter: 'all' }` 与三个纯函数。
2. 写 `storage.js`：`save(state)` 与 `load()`，`load` 用 `try/catch`。
3. 写 `render.js`：一个 `render(state)` 函数负责全量重绘列表与统计，先不做增量优化。
4. 写 `events.js`：用一个 `click` 委托处理勾选与删除，一个 `keydown` 委托处理回车与 Esc。
5. 写 `index.js`：加载数据 → 渲染 → 绑定事件 → 每次状态变化后 `save` + `render`。
6. 加筛选按钮与空状态。
7. 打开 Performance 面板，确认输入时没有明显长任务。

## 验收清单
- [ ] 六项功能全部可用，刷新后数据保持。
- [ ] 列表渲染使用 `DocumentFragment`，代码中没有 `innerHTML` 赋值。
- [ ] 所有列表事件通过委托绑定，动态新增的项无需重新绑事件。
- [ ] 输入 `<img src=x onerror=alert(1)>` 后界面只显示纯文本，不弹窗。
- [ ] `localStorage` 里被手动写坏成非法 JSON 时，页面仍能正常打开。
- [ ] 键盘可完成新增、勾选、删除、编辑与取消编辑。
- [ ] 能口述一次「点击删除按钮」的完整数据流：事件 → action → store 更新 → save → render。

## 加分项
1. 给新增与删除加动画（只用 `transform` 与 `opacity`）。
2. 增加「清除已完成」按钮与撤销上一次操作（提示：保存上一次快照）。
3. 把 `store.js` 改造成发布订阅模式：`subscribe(listener)`，状态变化自动通知渲染层。
4. 加并发上限的任务队列：批量导入任务时最多同时处理 3 个「模拟请求」。
