## 三条纪律

1. **优先 `const`**：只有确实要重新赋值时才用 `let`，永远不用 `var`。
2. **默认 `===`**：只有明确需要类型转换时才用 `==`。
3. **先搞清执行顺序再写异步**：不确定时，`console.log` 顺序是最好的老师。
